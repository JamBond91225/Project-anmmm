1. এই ZIP এর সব ফাইল GitHub Repo তে আপলোড করুন
2. Codemagic.io তে গিয়ে GitHub Repo Connect করুন
3. Workflow = android-workflow Select করে Start Build দিন
4. Build শেষে APK Download করুন
